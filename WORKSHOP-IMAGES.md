# VINI — imagens das descrições do Workshop

Arquivos públicos usados nas descrições dos mods de Project Zomboid. Esta branch mantém a hospedagem independente dos anexos da galeria e das limpezas de cache da Steam. A branch main e o perfil permanecem inalterados.

Os nomes dos arquivos derivam de SHA-256. Não sobrescreva arquivos existentes nem remova esta branch. Para novas imagens, adicione arquivos com novos nomes e mantenha os anteriores. As descrições apontam para uma revisão fixa do Git, não para uma branch mutável.

Preserve animações, dimensões e conteúdo. Marcas e imagens de terceiros pertencem aos respectivos titulares. Este arquivo não concede licença sobre essas marcas ou imagens.

Nenhuma hospedagem garante disponibilidade eterna. Há cópia local e mapa dos links para recuperação.
